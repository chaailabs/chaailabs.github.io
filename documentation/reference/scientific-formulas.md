# Scientific formulas

For an unwrapped trajectory, the self mean-squared displacement is

\[
\mathrm{MSD}(t)=\frac{1}{N}\sum_i\langle|\mathbf r_i(t_0+t)-\mathbf r_i(t_0)|^2\rangle_{t_0}.
\]

In three dimensions, the Einstein self-diffusion coefficient is

\[
D=\lim_{t\rightarrow\infty}\frac{1}{6}\frac{d\,\mathrm{MSD}(t)}{dt}.
\]

An Arrhenius model uses

\[
D(T)=D_0\exp\left(-\frac{E_a}{k_B T}\right).
\]

Nernst–Einstein conductivity assumes independent carriers. Correlated motion, finite trajectory duration, finite-size effects, thermostat choice, phase changes and fit-window selection must be reported as limitations or corrected where possible.
