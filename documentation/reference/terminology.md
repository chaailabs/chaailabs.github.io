# Terminology

| Term | Meaning |
|---|---|
| Implemented | Present in code and exercised in its stated environment |
| Validated | Tested against explicit acceptance criteria for a defined domain |
| Experimental | Implemented or explored without a supported stability guarantee |
| Planned | Roadmap item, not an available capability |
| Production-oriented | Designed with operational concerns, without implying broad production adoption |
| Provenance | Traceable identity of inputs, software, execution and derived artifacts |
