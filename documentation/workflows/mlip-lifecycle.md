# MLIP lifecycle

1. Define the intended domain and decision observable.
2. Generate diverse, physically relevant reference configurations.
3. Split by material, trajectory or configuration regime to prevent leakage.
4. Train with versioned data and configuration.
5. Evaluate energy, force and stress errors by regime, including tails.
6. Test deformation behavior, short reference trajectories and long-run stability.
7. Validate task observables with uncertainty.
8. Acquire targeted configurations where uncertainty or failure is high.
9. Approve a model only for its documented domain.

Aggregate RMSE alone is not an acceptance criterion for production dynamics.
